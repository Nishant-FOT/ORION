# Fetch Resilience Score

Retrieve the composite country resilience score and its domain/pillar breakdown.

## Usage

Provide a two-letter ISO 3166-1 alpha-2 country code (e.g., `IN` for India, `US` for United States).

## Output

Returns:
- Composite resilience score (0-100)
- Domain-level breakdown (economic, political, social, etc.)
- Pillar-level scores
- Trend indicators
