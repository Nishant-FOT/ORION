## Product catalog

### `GET /api/product-catalog`

Returns the tier view-model. Cached in Redis under `product-catalog:v2` for 1 hour. Response carries an `X-Product-Catalog-Source` header so probes can tell cache hits from live fetches.

**Response**:

```json
{
  "tiers": [
    {
      "name": "Free",
      "description": "Get started with the essentials",
      "features": ["Core dashboard panels", "..."],
      "cta": "Get Started",
      "href": "https://orion.app",
      "highlighted": false,
      "price": 0,
      "period": "forever"
    }
  ],
  "fetchedAt": "2026-04-19T12:00:00Z",
  "cachedUntil": "2026-04-19T13:00:00Z"
}
```

### `DELETE /api/product-catalog`

Purges the cached catalog. Requires `Authorization: Bearer $RELAY_SHARED_SECRET`. Internal.

## Waitlist

### `POST /api/leads/v1/register-interest`

Captures an email into the Convex waitlist table. Turnstile-verified (native client sources bypass), rate-limited per IP. Part of `LeadsService`; see [Platform endpoints](/api-platform) for the request shape.
